Unity Game “Wiggles”

Overview 🗺️

This is a game I made for the subject “Unity Development” in school. The website I used for hosting has unfortunately shut down, so the game is not playable until I decide to upload it somewhere else, which I might do in the future. In the game you move your mouse up and down to control the worm, the goal is to collect all of the apples and to finish the levels.

Technologies Used 🛠️

  • Unity (2D)
  • C#
  • Paint.NET (creating sprites)
  • Suno (for background music)
