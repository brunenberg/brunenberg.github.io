Overview 🗺️

This is a daily puzzle game I made because I had some of those in my daily routine (Wordle, enclose.horse, daily LinkedIn games). I initially got the idea because I was having dinner and for some reason I was imagining how the objects on the table would have to be placed in order for light/lasers coming from the side to cover as much area as possible. I immediately wrote down the idea and started working on it the day after that. In about 2 weeks of working on it whenever I felt like it, I had a finished product, a puzzle generator and an algorithm I could use to quickly find the optimal solution(s) for any puzzle I gave it.

Technologies Used 🛠️

  • HTML + CSS
  • JavaScript
  • Supabase
  • Cloudflare Pages
