Pygame Galactic Gladiators

Overview 🗺️

This was an assignment for the subject “Python”. The goal was to create a game with Python + Flask or Pygame. I had to create a board game with four special square types and six types of pieces with their own abilities. The game is similar to Stratego, you can’t see the value of the pieces of your opponent and the goal is to capture their flag.

Technologies Used 🛠️

  • Python
  • Pygame (UI)
  • JSON (saved games)
