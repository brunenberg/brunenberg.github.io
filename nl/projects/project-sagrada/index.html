Project Sagrada

Overzicht 🗺️

‘Project Sagrada’ was een schoolproject en mijn eerste grote samenwerking: we werkten met een team van vijf tot acht personen (het team groeide door problemen in een andere groep). Via dit project maakte ik kennis met Git en GitHub. Ons doel was een online versie van het bordspel “Sagrada” te bouwen in JavaFX. We volgden een lijst met eisen om te zorgen dat het spel aan de verwachtingen voldeed.

Technologieën 🛠️

  • Activiteitsdiagrammen
  • Enhanced Entity‑Relationship‑diagram
  • Klassendiagram
  • Use‑case‑diagrammen
  • Java
  • JavaFX
  • MVC

Uitdagingen en oplossingen 🧗🏻

In het begin was ik voorzichtig met Git uit angst het project te verstoren. Met tijd, hulp van teamgenoten en oefening werd ik er handig in. Mijn skills en vertrouwen in versiebeheer zijn sindsdien sterk gegroeid.

Showcase 📸

Dit is niet het eindresultaat; recentere beelden kon ik niet zo snel terugvinden. Een nieuwe database opzetten en seeden kost wat tijd, dus dat doe ik mogelijk later.

Conclusie 🏁

Ik ben tevreden met het resultaat. Zeker voor een eerstejaars project met teamwork is de code en oplossing opvallend netjes georganiseerd. Onze inzet heeft zich echt uitbetaald.
