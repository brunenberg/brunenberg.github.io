Unity Game “Wiggles”

Overzicht 🗺️

Dit is een game die ik maakte voor het vak “Unity Development” op school. De site die ik gebruikte om te hosten is helaas offline gegaan, dus het spel is momenteel niet speelbaar totdat ik het ergens anders upload, wat ik mogelijk in de toekomst doe. In het spel beweeg je de muis omhoog en omlaag om de worm te besturen; het doel is alle appels te verzamelen en de levels te halen.

Gebruikte technologieën 🛠️

  • Unity (2D)
  • C#
  • Paint.NET (sprites maken)
  • Suno (achtergrondmuziek)
