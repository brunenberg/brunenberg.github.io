Unity Game “Zorblex the Exploder”

Zorblex the Exploder on Itch.io!

Overzicht 🗺️

In de eerste zes weken van de minor die ik volg (Game Design and Development), was de uitdaging een 2D‑game in Unity te maken in een team van ongeveer vijf personen. Het team bestond uit twee developers (waaronder ik), twee artists en één game designer. We kozen voor een game rond het concept van rocket jumping, dat meestal vaker in 3D‑games wordt gebruikt zoals Quake en Team Fortress 2. In het spel is het doel de levels te halen met zo min mogelijk kogels.

Gebruikte technologieën 🛠️

  • Unity / Unity 2D
  • C#
  • Paint.NET (sprites maken/bewerken)
  • Git / GitHub
