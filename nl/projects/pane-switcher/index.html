Pane Switcher

Overzicht 🗺️

‘Pane Switcher’ is een applicatie die ik maakte voor een programmeertoets op school. De opdracht was om binnen 90 minuten een voorbeeldapp na te bouwen. De app had een knop die, zodra je erop drukte, het uiterlijk van verschillende panelen aanpaste. Ik had het binnen de toetsduur af, maar heb het thuis verder aangescherpt voor een beter resultaat.

Technologieën 🛠️

  • Java
  • JavaFX
  • Eclipse

Uitdagingen en oplossingen 🧗🏻

De grootste hobbel was het gebruik van een StackPane, dat was nieuw voor mij. Tijdens de toets koos ik een omweg, maar later thuis merkte ik dat het eigenlijk veel eenvoudiger was dan gedacht.

Showcase 📸

Conclusie 🏁

Dit project leerde me: onbekende dingen gewoon proberen loont. Als ik tijdens de toets direct de StackPane had aangepakt, had ik waarschijnlijk alle punten gehaald.
